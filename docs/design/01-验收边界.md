# 桌面客户端验收边界

当前产品和工程架构统一见 [PROJECT.md](../../PROJECT.md)，运行入口见 [README.md](../../README.md)。本文件只定义可判定的验收条件，不构成已经完成的声明；历史实现通过 Git 追溯。

## 内置界面与来源一致性

- 安装包含实际页面、主题、字体和 Logo。页面 HTML/JS/静态资源从安装包读取，不访问或启动 Frontend 服务、不监听本机业务端口；业务请求使用已有 Server。
- `frontend:check` 离线校验同步产物与 manifest hash，包括根 design.md 原文快照；`frontend:check-upstream` 对照实际上游当前内容。离线快照通过不代表最新上游一致；代码来源检查不代替实际渲染。
- 使用相同身份、数据、主题和视口对照 Frontend，覆盖首页、登录、记录、剧本、平台、详情及权限范围内的管理页面。不能用假业务数据证明服务端一致性。
- 验证明暗主题、桌面与 390px、长文本、空数据、请求失败恢复、分页选择、确认弹层、键盘焦点和关闭恢复；无页面级横向溢出。

## 契约与真实服务

- 数据库结构只由 `video-server/backend/sql/schema.sql` 维护，安装包不包含业务 Python 引擎、本地业务数据库实现、SQL 维护或运行时准备链。
- 生成客户端与当前 FastAPI OpenAPI 一致，保留真实 HTTP 状态、错误码、字段、分页、文件流和上传协议；不提交 schema 副本或手写 DTO。
- 真实账户能够登录，重启后按服务端会话期限保留身份，查询该账户的服务端既有数据。失效会话与依赖故障按现有语义恢复。
- 导入、保存媒体、浏览报告和任务实时状态使用已有接口与 WebSocket/Cookie 协议。元数据成功、健康探针和匿名拒绝不能证明完整文件或真实账户业务流程通过。
- 不读取或输出凭据，不复制普通 Chrome Profile；旧本地用户数据与并行修改保留，未经授权不导入、上传或删除。

## 工程、安装与发布

- 类型、格式、相关单元测试、生产构建和 Electron 测试分别执行。夹具证明确定性边界，真实服务流程需单独验证。
- macOS 与 Windows 安装包分别验证，开发态结果不代替安装态。默认未签名配置不能冒充已完成签名、公证或公开发布验收。
- 最低系统、干净安装、升级、卸载、真实平台完整下载和真实模型分析未执行时，在交付中明确说明。安装包生成或 CI 配置不代表这些场景已通过。
- 删除旧实现同步清理源码、依赖、入口、测试和文档，检查无悬空引用；不通过删除业务回归测试掩盖功能损坏。
