# 桌面客户端验收边界

本文定义可判定的验收条件，不代表已完成。架构见 [PROJECT.md](../../PROJECT.md)。

## 内置界面与来源一致性

- 安装包包含页面、主题、字体与 Logo；页面 HTML/JS/静态资源从安装包读取，不访问或启动 Frontend 服务，不监听本机端口；业务请求发往已有 Server。
- `frontend:check` 通过（含根 `design.md` 快照）；需要证明与最新上游一致时，`frontend:check-upstream` 通过。源码一致不代替实际渲染。
- 以相同身份、数据、主题与视口对照 Frontend，覆盖首页、登录、记录、剧本、平台、详情与权限范围内的管理页面；不得用假数据证明一致。
- 明暗主题、桌面与 390px、长文本、空数据、请求失败恢复、分页选择、确认弹层、键盘焦点与关闭后焦点恢复均可用，且无页面级横向溢出。

## 契约与真实服务

- 安装包不包含业务后端、本地业务数据库或 SQL；数据库结构只由 `framefetch-server/backend/sql/schema.sql` 维护。
- 生成 API 与当前 FastAPI OpenAPI 一致，保留真实 HTTP 状态、错误码、字段、分页、文件流与上传协议。
- 真实账户可登录；重启后按服务端会话期限保留身份，并能查询该账户已有数据；会话失效与依赖故障按 Server 语义恢复。
- 导入、保存媒体、浏览报告与任务实时状态使用已有接口与 WebSocket/Cookie 协议。元数据成功、健康探针与匿名拒绝不能证明完整文件或真实账户流程通过。
- 不读取或输出凭据，不复制普通 Chrome Profile；未经授权不导入、上传或删除本地用户数据。

## 工程、安装与发布

- 格式、类型、单元测试、生产构建与 Electron 测试分别执行并报告。
- macOS 与 Windows 安装包分别在目标系统验证，开发态结果不代替安装态。
- 默认未签名配置不能冒充已完成签名、公证或公开发布。最低系统、干净安装、升级、卸载、真实平台完整下载与真实模型分析未执行时，在交付中明确列出。
- 删除实现时同步清理源码、依赖、入口、测试与文档，且无悬空引用。
