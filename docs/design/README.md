## 需求与假设

- 用户明确要求：基于 Electron，新建 `video-electron`，作为可打包、可独立分发、不依赖自行部署服务器的桌面产品。
- 用户确认：首批 macOS + Windows；首版 AI 使用用户自己的模型 API，本地模型为后续可选接入。
- 规划假设：个人本地工作区；Linux、Windows ARM64、应用商店发布和云同步不纳入首批。
- 建议支持基线：macOS 14+，arm64/x64 分包；Windows 11 x64。这是产品测试范围建议，不是 Electron 官方最低系统要求。Windows 10 如需支持，应单独增加安装与运行验收范围。
