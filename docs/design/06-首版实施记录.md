# 独立桌面端首版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现可独立构建运行的Electron桌面工作站，形成本地媒体/文档、下载、可选BYOK分析与安装资源的真实闭环。

**Architecture:** React renderer通过窄preload调用Electron main，main监督stdio Python引擎。Python维护SQLite任务/资产，媒体在子进程处理；安装资源外置ASAR。

**Tech Stack:** Electron、React、TypeScript、electron-vite、electron-builder、pnpm；Python 3.12、Pydantic、SQLite、uv、PyInstaller、FFmpeg/ffprobe、yt-dlp。

**Spec:** [本地架构](02-本地架构与复用边界.md)、[存储与安全](03-任务存储与安全边界.md)、[分阶段验收](05-实施阶段与验收.md)。

## Global Constraints

- 首批目标为macOS arm64/x64和Windows x64；本机是macOS arm64，其他目标必须独立验收。
- 不依赖部署server、Docker、PG、MinIO、MQ或Temporal，不修改相邻项目。
- stdio单消息上限1 MiB；协议主版本1；握手5秒；stdout只用于协议。
- 引擎是SQLite唯一业务owner；媒体原件不被分析/导出改写；未知模型调用不自动重发。
- AI使用用户自备API；本地模型后置，默认不调用任何用户模型。
- 本次按职责并行实施，由父代理统一集成与最终审查；用户“开始展开实现”作为执行授权，不重复请求批准。

## Review Focus

- 原文件在复制/抽帧期间被改写：快照hash不符时终止，不能把新内容绑定旧hash。
- 取消与发布发生竞态：旧attempt及恢复流程不能将cancelled改为succeeded。
- main/engine/worker被杀：子树终止，重启后不伪造成功。
- 非法IPC/URL/媒体协议路径：拒绝越权系统操作与私网下载。
- 冻结安装包缺少动态库或资源：离线启动必须报告具体问题，不能借用开发机器PATH。
